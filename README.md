# ¿Qué prefieres? 🤔

Versión en español de *Would You Rather* para jugar en grupo, offline, en un solo celular.

- 290 preguntas en 9 categorías, incluida 🇨🇴 Colombianas (Picante apagada por defecto)
- Votación del grupo con porcentajes y reto para la minoría
- Tus propias preguntas
- Las preguntas no se repiten hasta agotar las elegidas

Preguntas en `app/src/main/assets/preguntas.json`. El APK se compila con GitHub Actions y se publica en Releases (una versión por cada `versionName`).
